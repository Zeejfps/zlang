# KOTOR in ctxlang

A reimplementation of *Star Wars: Knights of the Old Republic* in ctxlang, running the original
game's data. You need a copy of the game; this repository holds no game files.

```
kotor/tools/ctxc exe kotor -o kotor/out/kotor.exe
kotor/out/kotor.exe --game F:/Steam/steamapps/common/swkotor
```
